# homebrew-tap

```sh
brew tap benedict-armstrong/tap
brew trust --tap benedict-armstrong/tap   # once; Homebrew 7+ requires trusting third-party taps
brew install --cask benedict-armstrong/tap/publibike
```

| Cask | Description |
|---|---|
| [`publibike`](https://github.com/benedict-armstrong/publibike-bar) | Menu bar app showing live PubliBike / Velospot bike availability |
